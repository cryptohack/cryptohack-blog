Hello CryptoHackers! It's been ages since our last challenge release. In this release we are adding a new category on Zero-Knowledge proofs.

#### Platform Changes

We have a cool new career posting for a company called Aztec that is working on blockchain privacy and looking for crypto hackers (<a href="https://cryptohack.org/careers/aztec/">https://cryptohack.org/careers/aztec/</a>). 

Due to popular request, it will be possible to view the flags of challenges you've previously solved. Thanks to Robin for adding the code for this.

Previously our starting challenges used telnetlib to make TCP socket connections. We did this because telnetlib was part of the Python standard library and didn't require installing anything. However telnetlib is getting removed from Python 3.13. So we've rewritten the challenges to fully promote the use of Pwntools.

### New Challenge Descriptions

The main feature of this challenge release will be a whole new category on Zero-Knowledge Proofs contributed by <a href="https://cryptohack.org/user/Ectario/">Ectario</a>. We're really excited to be adding this to the platform, which fills a much-needed gap on the site by teaching ZKP in a similar style to the existing CryptoHack categories.

Additionally, the two "WOTS Up" challenges will be moved from the CTF Archive to the Post-Quantum section and given points ratings. That's because those challenges are about fundamental vulnerabilities that can occur in Hash-based cryptography. If you want to get ahead of the upcoming release, then get those solved now!
